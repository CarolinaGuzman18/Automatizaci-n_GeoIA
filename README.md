**Bitácora GEO**



**Descripción**



Repositorio de aprendizaje para documentar el proceso de formación en herramientas geoespaciales, Python y automatización de procesos con ArcGIS.



**Objetivos**



* Documentar los avances de aprendizaje.
* Registrar ejercicios y prácticas realizadas.
* Guardar ejemplos de código.
* Llevar un seguimiento de los conocimientos adquiridos.



**Herramientas**



* ArcGIS Pro
* Python
* Git
* GitHub
